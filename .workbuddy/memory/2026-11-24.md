## 工作台改造：多标签页（keep-alive）+ 布局视觉升级
- **核心架构变更**：废弃 `App.tsx` 里的 `<Routes>/<Route> + <Outlet>`（切换路由会卸载组件导致状态丢失）。改为自维护标签工作区：
  - 新增 `src/stores/useTabsStore.ts`（zustand）：tabs 列表 / activeKey / openTab / activateTab / closeTab；首页 tab 固定不可关闭，关闭当前标签返回相邻 path。
  - 新增 `src/config/toolComponents.ts`：`path -> lazy(组件)` 映射 + `tabMetaFromPath`（从 tools.json 取标题/图标）。**新增工具时需在此处补一条**（替代原 App.tsx 的 Route 注册）。
  - 新增 `src/components/layout/TabWorkspace.tsx`：监听 `useLocation().pathname` → openTab+激活；把**所有已打开标签的面板全部挂载**，堆叠在同一个 CSS Grid 单元格（gridArea: 1/1），非激活用 `visibility:hidden + pointer-events:none + zIndex:0` 隐藏（**不用 display:none**，避免 CodeMirror/PDF 等按容器测量尺寸的组件量到 0）。这样切换标签不卸载组件，输入内容/滚动位置全保留。URL（HashRouter）仍是唯一真相源，前进后退/侧边栏/卡片点击都走同一路径。
  - 新增 `src/components/layout/TabBar.tsx`：IDE 风格标签栏，点击 navigate、关闭按钮、中键关闭、横向滚动隐藏滚动条。
  - `App.tsx` 精简为 `<Router><MainLayout/></Router>` + Toaster。
- **导航无需改动**：工具卡片/侧边栏/breadcrumb 仍用 `<Link>`/`navigate`，location 变化自动触发开标签。
- **视觉升级**（quiet density，参考 Linear/Vercel）：`MainLayout.tsx` 侧边栏加品牌渐变图标/分类计数角标/底部隐私卡片，Header 加 ⌘K 聚焦搜索 + 首页快捷入口；`ToolsListPage.tsx` 加 Hero 区（渐变+网格纹理）+ 分类 chips + 全部视图按分类分组；`ToolCard.tsx` 图标渐变+hover 抬升；`tailwind.css` 追加 `.hero-banner/.tabbar/.tab-panel/.tool-icon` 等样式。

## 首页去 Hero + 滚动条移到外层容器
- 用户反馈：首页顶部大 Hero 标题不需要；滚动条在每个面板内部看着怪，要移到最外层容器。
- **删除 Hero**：`ToolsListPage.tsx` 移除 `.hero-banner` 区块 + `CATEGORY_DESC` 常量；`tailwind.css` 删除 `.hero-banner/.hero-pill/.hero-mark` 样式。
- **滚动策略调整**（注意 keep-alive 与工具页 `h-full` 的约束）：
  - `MainLayout.tsx` 的 `<main>` 从 `overflow-hidden` 改为 `overflow-y-auto overflow-x-hidden`（外层滚动容器）。
  - `TabWorkspace.tsx`：容器从 `grid h-full` 改为 `relative w-full min-h-full`；面板不再统一 gridArea 堆叠 + overflow-auto。改为：**激活的首页面板** `relative w-full min-h-full`（自然高度，内容溢出到 main → 滚动条贴外层右侧）；**工具页/非激活面板** `absolute inset-0 w-full overflow-hidden`（脱流，保持可视区尺寸给 CodeMirror 测量，不干扰外层滚动高度）。
  - 加了 `homeScrollRef` + `prevActiveRef`：离开首页记下 main.scrollTop，切回首页恢复，工具页回顶部。
  - 关键点：工具页根节点是 `h-full` + 内部分栏滚动，必须保持填满可视区（所以走 absolute inset-0），否则 h-full 塌陷。
