## 修复：侧边栏分类点击不导航的 bug
- 现象：在工具详情页点左侧分类，仅地址变了、视图不跳。
- 根因：项目用 `HashRouter`（路由在 `#` 后）；`setCategory` 用 `window.history.replaceState({}, '', '/')` 手改地址，既不触发 React Router 导航（Router 只监听 `popstate`），又抹掉了 hash 里的路由。
- 修复：
  1. `src/stores/useUiStore.ts`：`setCategory` 仅更新状态，删除 `replaceState`；`readLocation` 改为解析 `location.hash`（HashRouter 下 query 在 hash 里），使 `syncWithLocation`（popstate 时）能正确读回分类。
  2. `src/layouts/MainLayout.tsx`：Sidebar 用 `useNavigate`，点击分类时 `setCategory(id)` + `navigate(to, { replace: true })`，`to` 为 `/?category=<id>` 或 `/`。
- 验证：`tsc` 改动文件 0 报错；`vite build` 通过。

## 修复：json-viewer 报 "expects value to be string, got object"
- 现象：进入 JSON 查看器、输入合法 JSON 预览时报错。
- 根因：`@_1602/json-viewer` 的 `set value(e)` setter 要求 `value` 为 JSON 字符串（内部 `JSON.parse`）；原代码把解析后的**对象** `value={parsed}` 当 property 传入，触发 setter 的类型检查报错。
- 修复：`src/tools/json-viewer/index.tsx` 改为 `value={JSON.stringify(parsed)}`；`src/types/json-viewer.d.ts` 的 `value` 类型由 `unknown` 收紧为 `string`（以后误传对象会被 tsc 拦下）。
- 验证：`tsc` 0 报错；`vite build` 通过。

## 修复：JSON 查看器长字段挤压整页布局 + 新增全屏预览
- 现象：JSON 字段值过长时，查看器内部虽出现滚动条，但整页仍被撑宽变形，内容越长越严重。
- 根因：右侧 flex 链（行容器 / 右面板 / 结果容器）缺 `min-w-0`，flex 子项默认 `min-width:auto`=内容最小宽度，被长 nowrap 行撑大 → 顶宽整页。
- 修复：
  1. `src/styles/tailwind.css`：`json-viewer` host 显式加 `width:100%; max-width:100%; min-width:0;`（配合已有 `display:block; overflow:auto`，超长内容在查看器内部滚动）。
  2. `src/tools/json-viewer/index.tsx`：给行容器、右面板、结果容器补 `min-w-0`。
  3. 新增全屏预览：`isFullscreen` 状态 + 右面板工具栏「全屏」按钮 + `fixed inset-0 z-[100]` 浮层（含复制/退出全屏，Esc 退出）。
- 验证：`tsc` 0 报错；`vite build` 通过。

## 修复：长 JSON 仍把整页（body）撑出横向滚动条
- 现象：内部虽有滚动条，但整页（body）仍横向滚动，内容越长越严重。
- 分析：json-viewer 工具根容器 `flex + overflow-hidden`（块级填充父宽 + 裁剪）本应关住宽内容；但实测 body 仍溢出，疑似 flex 跨轴 min-width 传播 + 视口层未裁切。
- 修复：
  1. `src/styles/public.css`：给 `html` 加 `overflow-x:hidden`（视口兜底，挡掉整页横向滚动条；纵向滚动行为不变，html 本就是视口纵向滚动器）。
  2. `src/layouts/MainLayout.tsx`：内容区与 `main` 加 `min-w-0`，长内容下面板保持比例不被挤压。
  3. 保留 json-viewer 链路的 `min-w-0` + host `width:100%;min-width:0;overflow:auto`。
- 注意：`min-w-7xl`（1280px 最小宽）在窗口 < 1280px 时会被 `overflow-x:hidden` 裁掉而非横向滚动；若用户希望小屏可滚动需再调整。
- 验证：`tsc` 0 报错；`vite build` 通过。

## 新增「PDF 转图片」工具
- 新增独立工具 `pdf-to-image`（路径 `/tools/pdf-to-image`），归属新分类 `document`（文档工具）。
- 库：`pdfjs-dist` 6.1.200（Mozilla PDF.js，纯前端本地渲染，无 React 依赖）。`jszip` + `file-saver` 项目已装，复用做 ZIP 打包与下载触发。
- 功能：选/拖 PDF → 逐页渲染到 canvas（可设倍率 1/1.5/2/3x、质量）→ 预览网格（页码+尺寸）→ 三种导出：逐页下载、ZIP 打包、合成长图（可设页间隙 px，白底）。
- **pdfjs v6 接入要点（易踩坑）**：
  - worker：`import workerSrc from 'pdfjs-dist/build/pdf.worker.min.mjs?url'`，再 `GlobalWorkerOptions.workerSrc = workerSrc`（Vite 下 `?url` 直接产出 worker 资源，构建已验证）。
  - 渲染 API：`page.render({ canvas, viewport })`（v6 用 `canvas` 字段，`canvasContext` 已废弃）。
  - `PDFDocumentProxy` 类型**未声明** `destroy()`，但运行时有；释放资源需 `(pdf as unknown as {destroy:()=>Promise<void>}).destroy()` 安全断言。
  - 文档自带类型（`types/src/pdf.d.ts`），`getDocument`/`GlobalWorkerOptions`/`PDFDocumentProxy` 均可 `import type`；`moduleResolution: bundler` 下无需 `@types/pdfjs-dist`。
- 改动文件：`src/tools/pdf-to-image/index.tsx`（主组件）、`utils/render.ts`、`utils/export.ts`；`src/config/categories.json`（加 document）；`src/layouts/MainLayout.tsx` iconMap 加 `document:'i-lucide-files'`；`src/config/tools.json`；`src/App.tsx`（lazy+Route）；`package.json`（加 pdfjs-dist）。
- 验证：`tsc --noEmit` 新文件 0 报错；`vite build` 通过（worker 作为独立 asset 产出，jszip 已打包）。
- 说明：pdfjs-dist 经 `/tmp` npm 干净安装后拷回 `node_modules`（沙箱 pnpm 不可用）；`pnpm-lock.yaml` 未更新，正常环境需 `pnpm add pdfjs-dist` 同步。

## 改造：JSON 查看器输入框换成 CodeMirror（解决"看不出哪行出错"）
- 诉求：原 `<Textarea>` 无行号，JSON 报错时看不出具体行。
- 方案：改用 `@uiw/react-codemirror` 4.25.11（peerDeps react>=17，兼容 React 19）+ `@codemirror/lang-json` 6.0.2 + `@codemirror/lint` 6.9.7。
  - `basicSetup` 默认含行号（`lineNumbers`）、`foldGutter`、`highlightActiveLine`；加 `json()` 做语法高亮；加 `linter(jsonParseLinter())` 实现**出错行实时标红波浪线**（核心痛点解决）。
  - `onChange` 改为静默实时预览（`doPreview(val, true)` 不弹 toast），输入即更新右侧树 + 行内标红。
  - 主题跟随：组件内 `useState` 读 `document.documentElement.classList.contains('dark')`，并用 `MutationObserver` 监听 `<html>` class 变化，传 `theme={isDark?'dark':'light'}`。
  - 长行：`.json-cm .cm-scroller { overflow-x:auto }` 内部横向滚动，不撑破左面板。
- 安装：三个包经 `/tmp` npm 干净安装后拷回 `node_modules`（含 `@uiw`/`@codemirror`/`@lezer`/`@marijn`/`@babel`/`style-mod`/`w3c-keyname`/`crelt`/`codemirror` 整套子依赖；**不拷 react/react-dom/scheduler**，避免重复 React 实例）；`package.json` 登记三个包。
- 注意：`@uiw/react-codemirror` 自带类型（`esm/index.d.ts` 存在）但 `package.json` 缺 `types` 字段；`moduleResolution:bundler` 下经 `main`(cjs) 的 `index.d.ts` 可解析，tsc 0 报错。若日后提示缺类型，补 `declare module '@uiw/react-codemirror'` shim 即可。
- 验证：`tsc --noEmit` 新文件 0 报错（仅预存 json-to-ts 错误）；`vite build` 通过（31s，CodeMirror 已打包）。
