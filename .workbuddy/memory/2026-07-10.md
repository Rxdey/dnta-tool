## 环境注意事项（重要）
- 本沙箱 `pnpm` 走 corepack 但缺 pnpm.js，调用失败；`npm install` 在 pnpm 风格的 node_modules 上会报 `Cannot read properties of null (reading 'matches')`。
- 安装新依赖的临时方案：在 `/tmp` 用 `npm install` 干净安装，再把 `node_modules/<pkg>` 拷回项目；或 `npm install --no-package-lock` 失败时同样用拷贝法。
- 因 pnpm 不可用，`pnpm-lock.yaml` 未能更新；用户需在正常环境跑一次 `pnpm install` 同步锁文件。
- 项目预存 tsc 错误（与本次无关）：`src/tools/json-to-ts` 的 `prismjs` 缺类型声明、`convert.ts` 的 `groupItems` 可能 undefined。项目实际构建命令是 `vite build`（不跑 tsc）。

## 修复：侧边栏分类点击不导航的 bug
- 现象：在工具详情页点左侧分类，仅地址变了、视图不跳。
- 根因：项目用 `HashRouter`（路由在 `#` 后）；`setCategory` 用 `window.history.replaceState({}, '', '/')` 手改地址，既不触发 React Router 导航（Router 只监听 `popstate`），又抹掉了 hash 里的路由。
- 修复：
  1. `src/stores/useUiStore.ts`：`setCategory` 仅更新状态，删除 `replaceState`；`readLocation` 改为解析 `location.hash`（HashRouter 下 query 在 hash 里），使 `syncWithLocation`（popstate 时）能正确读回分类。
  2. `src/layouts/MainLayout.tsx`：Sidebar 用 `useNavigate`，点击分类时 `setCategory(id)` + `navigate(to, { replace: true })`，`to` 为 `/?category=<id>` 或 `/`。
- 验证：`tsc` 改动文件 0 报错；`vite build` 通过。

## 修复：json-viewer 报 "expects value to be string, got object"
- 现象：进入 JSON 查看器、输入合法 JSON 预览时报错。
- 根因：`@_1602/json-viewer` 的 `set value(e)` setter 要求 `value` 为 JSON 字符串（内部 `JSON.parse`）；原代码把解析后的**对象** `value={parsed}` 当 property 传入，触发 setter 的类型检查报错。
- 修复：`src/tools/json-viewer/index.tsx` 改为 `value={JSON.stringify(parsed)}`；`src/types/json-viewer.d.ts` 的 `value` 类型由 `unknown` 收紧为 `string`（以后误传对象会被 tsc 拦下）。
- 验证：`tsc` 0 报错；`vite build` 通过。

## 修复：JSON 查看器长字段挤压整页布局 + 新增全屏预览
- 现象：JSON 字段值过长时，查看器内部虽出现滚动条，但整页仍被撑宽变形，内容越长越严重。
- 根因：右侧 flex 链（行容器 / 右面板 / 结果容器）缺 `min-w-0`，flex 子项默认 `min-width:auto`=内容最小宽度，被长 nowrap 行撑大 → 顶宽整页。
- 修复：
  1. `src/styles/tailwind.css`：`json-viewer` host 显式加 `width:100%; max-width:100%; min-width:0;`（配合已有 `display:block; overflow:auto`，超长内容在查看器内部滚动）。
  2. `src/tools/json-viewer/index.tsx`：给行容器、右面板、结果容器补 `min-w-0`。
  3. 新增全屏预览：`isFullscreen` 状态 + 右面板工具栏「全屏」按钮 + `fixed inset-0 z-[100]` 浮层（含复制/退出全屏，Esc 退出）。
- 验证：`tsc` 0 报错；`vite build` 通过。

## 修复：长 JSON 仍把整页（body）撑出横向滚动条
- 现象：内部虽有滚动条，但整页（body）仍横向滚动，内容越长越严重。
- 分析：json-viewer 工具根容器 `flex + overflow-hidden`（块级填充父宽 + 裁剪）本应关住宽内容；但实测 body 仍溢出，疑似 flex 跨轴 min-width 传播 + 视口层未裁切。
- 修复：
  1. `src/styles/public.css`：给 `html` 加 `overflow-x:hidden`（视口兜底，挡掉整页横向滚动条；纵向滚动行为不变，html 本就是视口纵向滚动器）。
  2. `src/layouts/MainLayout.tsx`：内容区与 `main` 加 `min-w-0`，长内容下面板保持比例不被挤压。
  3. 保留 json-viewer 链路的 `min-w-0` + host `width:100%;min-width:0;overflow:auto`。
- 注意：`min-w-7xl`（1280px 最小宽）在窗口 < 1280px 时会被 `overflow-x:hidden` 裁掉而非横向滚动；若用户希望小屏可滚动需再调整。
- 验证：`tsc` 0 报错；`vite build` 通过。
